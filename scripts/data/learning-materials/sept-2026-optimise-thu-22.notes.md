# 22 Oct Workshop · Optimisation and Q&A (22 October 2026)

Thursday 18:00–19:00. Speaker: Renuka Kelkar. Week 4 (Optimise pillar).

Continues the 17 October Optimise workshop (harnessing, tools vs prompts, dry-run, measure, cost formula). This hour covers right-sizing models, analytics/traces, and evaluation, plus open Q&A so agents are ready for the 31 October Agentic Hackathon.

## Takeaways

- Cheap/Flash models for routing, classification, validation; stronger models only for planning/reasoning
- Traces and metrics: tokens, tool calls, retries, failures
- Evaluate before spending on production Vertex / media APIs
- Apply ADK harness patterns from the Saturday session to your own project
